# QA3 — чек-лист Founder (обновлён 2026-10-08)

Где: `https://preview.oruwa.jp`. Аккаунты: Manager `manager@oruwa-cafe.test`,
Staff A 田中 美咲 (`konstantin.a.chvykov@gmail.com`), Staff B 佐藤 陽介
(`+staffb`, сначала примите приглашение из почты и задайте пароль),
Staff C 鈴木 健太 (`+staffc`). Удобно: Manager в одном окне, Staff — в
окне инкогнито.

Отметки: **[НОВОЕ]** — появилось или изменилось 7–8 октября (PR #557–#562),
проверьте внимательно. Остальное уже проверено мной вживую 7 октября; вам —
посмотреть глазами владельца: понятно ли, удобно ли, правильно ли по-японски.

Найденное записывайте так: «блок → что сделал → что ожидал → что увидел»
(скриншот приветствуется).

## 1. Вход и роли
- [ ] Manager и Staff входят; выход через меню имени.
- [ ] Staff открывает `/manager` вручную → доступ закрыт (известно: экран на английском, DEBT-053).
- [ ] [НОВОЕ] Staff B: принять приглашение из почты `+staffb` → задать пароль → попасть на экран Staff.

## 2. Пожелания по сменам [НОВОЕ]
- [ ] Staff: «来月のシフト希望を提出» → нажатия по дню: «—» → «休み» → смены → «—».
- [ ] Отправить пустое → ошибка; после нажатия на день ошибка исчезает.
- [ ] Отправить: 1 день смена, 1 день «休み», остальное «—». Открыть снова → отправленные дни заблокированы.
- [ ] Справка «?» у Staff понятна.
- [ ] Manager: Settings → «シフト希望» показывает «来月分 N/M名提出済み».
- [ ] «希望を見る» → открывается на «来月»; переключатель «今月».
- [ ] В сетке: смена — цветной номер, «休», «—» = нет пожелания.
- [ ] Нажать на смену или «休» → «確認済みにする» → значок ✓; закрыть/открыть/перезагрузить → ✓ остаётся; «確認済みを取り消す» работает.
- [ ] Имя с красным «!» → «リマインダーを送信» → письмо приходит сотруднику (у тестовых — в ваш ящик).
- [ ] На телефоне (узкий экран) сетка читается.

## 3. Недельный график и публикация [НОВОЕ]
- [ ] Manager назначает смену в ячейке → Staff видит её через несколько секунд без перезагрузки.
- [ ] Изменить уже видимую смену → предупреждение «予定済みのシフトを変更しますか？».
- [ ] Перейти на будущую неделю → Settings «自動でシフトを作成» → результат: создано N, нехватки, кто без пожеланий.
- [ ] [НОВОЕ] В результате и в Settings — «この週の未公開シフト: N件» и «この週のシフトを公開» → подтвердить → «N件のシフトを公開しました» → Staff видит неделю.
- [ ] Сотрудник с «休み» на этот день не получил смену.
- [ ] «自動作成を取り消す» до публикации удаляет черновики.
- [ ] После проверки удалить созданные смены, если не нужны (ячейка → «シフトを削除»).

## 4. Обмен, изменение, отмена смены
- [ ] Staff: своя будущая смена → «交換希望» с причиной → на ячейке «!».
- [ ] Manager: «シフト交換» → «交換相手を指名» → «承認» → смена у другого сотрудника, Staff видит.
- [ ] То же для «別のシフト種別を希望» и «キャンセル希望».
- [ ] [НОВОЕ] Старые заявки на прошедшие даты помечены «期限切れ», есть только «却下».

## 5. Коррекция посещаемости
- [ ] Staff: прошедшая смена → «修正を依頼» → время и причина.
- [ ] Manager: «勤怠修正» → «承認» → у Staff факт исправлен, «承認済み».
- [ ] «却下» — заявка уходит в историю, факт не меняется.

## 6. Приход, уход, транспорт, деньги [НОВОЕ]
- [ ] Staff: «出勤» → «勤務中・HH:MM〜» → «退勤» → выбор перерыва → подтверждение.
- [ ] Повторный приход в тот же день невозможен.
- [ ] Транспорт: ввести сумму → «保存しました» → после перезагрузки сохранено.
- [ ] [НОВОЕ] Заработок у Staff и «概算人件費» у Manager считаются по точным минутам.
- [ ] [НОВОЕ] Manager: нажать на имя сотрудника → часы с «h», ставка и сумма с «¥».

## 7. Mail [НОВОЕ]
- [ ] Staff пишет → у Manager «未読メール 1».
- [ ] Manager отвечает → [НОВОЕ] у Staff кнопка «メール 1» появляется сама (до 30 секунд), без перезагрузки.
- [ ] Staff B и Staff C не видят чужую переписку.
- [ ] «•••» → архив сообщения.

## 8. Сотрудники
- [ ] Добавить сотрудника (с часовой ставкой) → изменить должность → ставка не пропала.
- [ ] «招待する» → письмо приходит (сейчас на английском, DEBT-083 — японский шаблон готов).
- [ ] «無効化» → сотрудник исчезает из графика; «有効化» возвращает.
- [ ] «完全に削除» для сотрудника без истории; для сотрудника с историей — запрет.

## 9. Рецепты
- [ ] Создать рецепт, привязать ингредиент к складу → у Manager «材料費目安» и аллергены.
- [ ] Staff: тот же рецепт — аллергены видны, цены нет, редактирования нет.
- [ ] Переключить EN → название и шаги переведены.
- [ ] Архив / удаление.

## 10. Склад и закупки
- [ ] Staff: пересчёт ниже точки заказа → «不足».
- [ ] Manager: «在庫不足» в «要確認», кто пересчитал — видно только Manager.
- [ ] Закупка: «購入済み» или «発注» → «入荷» с количеством → остаток вырос, позиция ушла из списка.
- [ ] История закупок.

## 11. Операции (HACCP) [НОВОЕ]
- [ ] Staff: «オペレーション» → задача на сегодня → отметить пункты → «タスクを完了する» → только чтение.
- [ ] Manager: шаблон → у температурного пункта задать диапазон (например 0–5 °C).
- [ ] [НОВОЕ] Staff вводит значение вне диапазона → жёлтое предупреждение «目安の範囲外の値です…».
- [ ] [НОВОЕ] Manager: «対応が必要» → исключение с текстом на японском, текущим значением и диапазоном → «解決する» с заметкой.
- [ ] Известно: копятся сотни просроченных проверок за прошлые дни (DEBT-002), кнопки массового закрытия нет.

## 12. Проблемы и передача смены
- [ ] Staff: «報告する» → проблема, «重要» → красная цифра на кнопке.
- [ ] Manager: «確認する» → «解決する» → уходит в «履歴».
- [ ] «申し送りメモ» (информационная заметка).

## 13. Панель внимания и Weekly Review
- [ ] Цифры в «要確認» меняются вместе с вашими действиями.
- [ ] «週次レビュー» → прошлая и текущая неделя совпадают с тем, что вы сделали.

## 14. Настройки
- [ ] Нужное число людей по дням недели и лимит часов в месяц сохраняются сами.
- [ ] Тип смены: добавить → «無効化» → «再開» / «削除».
- [ ] Автосоздание по дню месяца — только настройка; сам ночной запуск пока не работает (DEBT-074, следующая миссия).

## 15. Язык и телефон
- [ ] Меню имени → EN / JA: все экраны переключаются.
- [ ] Всё основное — на телефоне.
