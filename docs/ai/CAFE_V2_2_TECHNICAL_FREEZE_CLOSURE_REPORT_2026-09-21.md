## 6. Оценочная стоимость труда («概算人件費»)

- **Источник часов:** отработанные часы **текущего календарного месяца** по завершённым парам `clockIn`/`clockOut` за вычетом перерыва (`workedHoursForMonth`); открытая смена и другие месяцы не считаются. Определение не менялось.
- **Источник ставки:** ставка каждого сотрудника (`hourly_wage_yen`); суммируется «часы × собственная ставка» по каждому, единой ставки нет.
- **Отсутствие ставки:** раньше `?? 0` превращало её в ¥0. Теперь: если ставки нет ни у кого — показывается «—»; если у части активных сотрудников нет ставки — под суммой строка «時給が未設定のN名は含まれていません» (сумма — нижняя граница). Ставка 0 остаётся реальным значением.
- **Проверено:** юнит-тесты (две разные ставки считаются независимо; перерыв; другие месяцы и открытая смена; отсутствующая ставка не даёт 0; ставка 0; неактивные) и живьём: после ставок A и B блок показывает «¥0» и «3名» (сначала «4名»), то есть счётчик неоценённых меняется по мере ввода ставок.
- **Не проверено вживую:** сумма с реальными часами у двух сотрудников. У Staff-аккаунта один сотрудник; собственная смена «сегодня» по дизайну не открывается для запроса исправления, а у прошлой недели нет приходов. Регистрирую как NOT TESTED (DEBT-060).
