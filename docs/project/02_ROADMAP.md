# ORUWA Operational Roadmap

This is a compact navigation view of the accepted direction. Normative sources are the [Portfolio & Module Strategy](../foundation/oruwa-portfolio-and-module-strategy.md) and [Platform Foundation Roadmap](../foundation/platform-foundation-roadmap.md). No dates are promised without evidence.

## Done

- Core platform and multi-tenant foundation established incrementally.
- Cafe v2.0 frozen baseline and subsequent v2.1 implementation slices.
- ORUWA Foundation v1.0 Frozen through PR #184.
- Cafe v2.1 Technical Baseline PR #185 and Manager confirmation PR #186 merged.

## Current

- Close Cafe v2.1 manual/live acceptance and technical evidence gaps.
- Resolve the audit-logging decision and obtain Founder acceptance.

## Next

- Complete remaining Cafe commercial-readiness and module research.
- Select and freeze Cafe v2.2 scope using purchase-probability and onboarding-impact evidence.
- Implement and accept Cafe v2.2.
- Prepare the repeatable Production Factory and validate the one-hour onboarding target by rehearsal before making a public claim.
- Prepare minimum customer portal, sites, sales kit, pricing, pilot offer, FAQ, and demo.

## Later

- Cafe Commercial Release and sales execution.
- Hardening v2 Lite and AI-assisted sales where evidence justifies them.
- Platform Foundation capabilities in the order needed by real customers and additional verticals.
- Research and select a second vertical; Salon/Cleaning/Booking-based packages are candidates, not committed releases.

## Deferred

- Clinic because of regulatory burden.
- Construction until platform maturity and separate authorization.
- Heavy billing, integrations, and ops-console work that does not unblock Cafe or a real customer.

## Never / non-target

- Tenant-specific code forks.
- Heavy procurement ERP inside Cafe Inventory.
- Unsupported AI automation or risky autonomous actions.
- Public one-hour onboarding claim before a successful rehearsal.
