# Cafe Workforce — デモスクリプト（5〜7分）

Status: **下書き。実際の会話ではカフェ側の反応に合わせて順番・時間配分を調整してよい。**

Read with: [`cafe-workforce-first-client-message-ja.md`](./cafe-workforce-first-client-message-ja.md),
[`cafe-workforce-client-interview-checklist-ja.md`](./cafe-workforce-client-interview-checklist-ja.md).

## 前提

- 対象デモ: `/demo/cafe`（スタッフアプリ）, `/demo/cafe/recipes`（レシピ共有）,
  `/demo/cafe/manager`（店長ダッシュボード）, `/demo/cafe/guide`（ガイドページ）。
- すべて確認用デモ。データ保存なし、LINE連携なし。この前提はデモ中に一度、
  自然な形で口頭でも伝える（ガイドページの免責表示と同じ内容）。
- 所要時間の目安は5〜7分。長くなりすぎる場合は3.スタッフアプリと6.店長
  ダッシュボードを優先し、4.レシピ共有は簡略化してよい。

## 進行

### 1. ガイドページを開く（0:00〜0:30）

- `/demo/cafe/guide` を開き、画面を見せながら「LINEで使えるカフェ運営ミニOS」
  という全体コンセプトを一言で紹介する。
- 「これは実際に動くデモなので、触りながら見ていただけます」と伝える。

### 2. 今の困りごとを言語化する（0:30〜1:30）

- 画面を進める前に、現状の運用を確認する会話を挟む。
- 触れる観点の例:
  - LINEグループでシフトや連絡が流れて埋もれてしまう。
  - 紙のシフト表やホワイトボードで管理している。
  - 新人への説明が口頭中心で、教える人によってバラつきがある。
  - シフトや売上集計をスプレッドシートで手作業しているため属人化している。
- ここで出た困りごとを、後の画面説明のときに「これがさっきの話に近いです」
  と紐づけると伝わりやすい。

### 3. LINEファーストという考え方を説明する（1:30〜2:15）

- 新しいアプリを覚える必要がなく、LINEのリッチメニューから開く前提である
  ことを説明する。
- 「スタッフさんが普段使っているLINEから、そのまま今日のシフトやレシピを
  確認できる」という一言で要点を伝える。
- 本番導入時にLINE公式アカウント・リッチメニュー・LIFFを組み合わせる想定
  であることには軽く触れるが、詳細説明はガイドページに譲ってよい。

### 4. スタッフアプリを見せる（2:15〜3:15）

- `/demo/cafe` を開く。
- 見せる操作: 出勤/退勤ボタン、休憩開始/終了、週間シフト表の左右スワイプ、
  交通費と日報の入力欄。
- 一言ポイント: 「ボタン2つだけで出退勤・休憩が完結する」「シフトはスワイプ
  でその場で見返せる」。

### 5. レシピ共有を見せる(3:15〜4:00)

- `/demo/cafe/recipes` を開く。
- 見せる操作: レシピ一覧から1件開き、材料・手順・補足メモを見せる。JA/EN
  切り替えがあれば軽く見せる。
- 一言ポイント: 「新しいスタッフや外国籍スタッフでも、聞かなくてもレシピを
  確認できる」。

### 6. 店長ダッシュボードを見せる（4:00〜5:30）

- `/demo/cafe/manager` を開く。
- 見せる操作: 週間シフト表、要確認アラート、シフト編集、月間レポート
  （CSVダウンロードはデモ表示である旨を伝える）。
- 一言ポイント: 「店長側は、シフトの抜け漏れや確認が必要な項目が一画面で
  わかる」「これが実際にお金を払ってもらう価値の中心になる部分」。

### 7. クロージングの質問（5:30〜6:30）

必ず以下の2つを、順番に、詰め寄らない自然なトーンで聞く。

1. 「今、一番困っている作業はどこですか。」
2. 「もし良ければ、8週間の無料パイロットで試してみたいですか。」

- 質問1の回答は
  [`cafe-workforce-client-interview-checklist-ja.md`](./cafe-workforce-client-interview-checklist-ja.md)
  のFollow-up notesにそのまま書き留める。
- 質問2で前向きな反応があれば、
  [`cafe-workforce-pilot-package-ja.md`](./cafe-workforce-pilot-package-ja.md) の内容
  （8週間無料・継続時月額4,980円・税別・LINE公式アカウント費用は別途）を
  そのまま説明する。

## 話してはいけないこと / 誤解させないこと

- 「もう本番で使えます」「データは保存されています」とは言わない。
- 「給与計算もできます」「法律上の勤怠管理の代わりになります」とは言わない。
- LINE連携が既に完成しているかのような言い方をしない（本番導入時に設計する
  部分であることを明確にする）。
