# Cafe Workforce — 8週間無料パイロットパッケージ

Status: **開発協力パイロットの提案内容。一般公開時の標準料金ではない。**

Read with: [`cafe-workforce-first-client-message-ja.md`](./cafe-workforce-first-client-message-ja.md),
[`cafe-workforce-pricing-notes.md`](./cafe-workforce-pricing-notes.md).

## 概要

| 項目 | 内容 |
| --- | --- |
| 対象 | カフェ1店舗（1店舗単位） |
| 期間 | 8週間 |
| 期間中の料金 | 無料 |
| 継続時の料金 | 月額4,980円（税別） |
| 初期費用 | 0円（今回の開発協力の第一号としての特別対応） |
| その他費用 | LINE公式アカウントの利用にともなう費用が発生する場合は別途 |
| 位置づけ | 開発協力パイロットであり、一般公開時の標準料金ではない |

この価格は、最初の開発協力先であるギュウさんの店舗に限定した条件であり、
将来の一般顧客向け料金とは別枠として扱う（一般料金の方向性は
[`cafe-workforce-pricing-notes.md`](./cafe-workforce-pricing-notes.md) を参照）。

## 含まれるもの（Included）

- スタッフアプリ（出勤・退勤、休憩管理）
- 店長ダッシュボード
- シフト確認
- シフト希望提出
- 勤務報告（日報）
- 日次メッセージ
- 交通費入力
- レシピ・マニュアル共有
- 簡易な月次レポート
- 週次のフィードバック確認（パイロット期間中、運用状況を一緒に振り返る場を
  週1回程度設ける）
- 小規模なUI・文言の調整（パイロット中に出た使いにくさへの軽微な修正対応）

## 含まれないもの（Excluded）

- 給与計算
- 法律上必要な勤怠管理（法定帳簿・労働時間の法的証跡としての利用）
- シフトの完全自動最適化
- POSシステム連携
- 会計システム連携
- LINEの一斉配信・マスメッセージ配信
- 大規模なカスタム開発
- 24時間サポート
- 法務・労務に関する相談対応（社会保険労務士・弁護士業務の代替ではない）

## 必要な情報（Required Information）

パイロット開始前に、以下をカフェ側からいただく想定。

- 店舗名・所在地・営業時間
- スタッフの人数・雇用形態（社員/アルバイト等）のおおよその内訳
- 現在のシフト作成・共有方法（LINE、紙、スプレッドシート等）
- 現在使っているLINE公式アカウントの有無（ある場合はその状況）
- パイロット期間中に主担当となる連絡窓口（店長など1名）

## 成功基準（Success Criteria）

パイロット終了時に、以下を一緒に確認する。

- スタッフがLINE経由でシフト・レシピを実際に日常的に確認しているか。
- 店長がシフト確認・要確認事項の把握にかかる時間が体感として減っているか。
- 紙・口頭・スプレッドシートでの運用が実際にどれだけ置き換わったか。
- 継続利用（月額4,980円・税別）を続けたいという意思が確認できるか。
- 追加してほしい機能・改善してほしい点が具体的に挙がっているか。

## 重要事項（Important Notes）

- これは開発協力パイロットであり、機能・料金ともに一般公開前の検証段階の
  内容である。
- これは給与計算システムではない。
- これは法律上の勤怠管理（法定帳簿・労働時間管理）を代替するものではない。
- パイロット期間中もデータの取り扱いには通常の運用と同等の注意を払うが、
  詳細な契約・秘密保持・データの取り扱い条件は別途合意する。
- LINE公式アカウントに関する費用（メッセージ配信料等）はLINE側の料金体系に
  依存するため、別途確認・別途負担となる。
